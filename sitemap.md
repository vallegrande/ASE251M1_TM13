# 🗺️ Sitemap - Wawalu Centro Educativo

## 📍 **Estructura del Sitio Web**

### 🏠 **Páginas Principales**
- **/** - Página de inicio
- **/nosotros** - Información sobre el centro educativo
- **/programas** - Programas educativos disponibles
- **/calendario** - Calendario de actividades y eventos
- **/noticias** - Noticias y actualizaciones del centro
- **/galeria** - Galería de fotos y actividades
- **/tienda** - Tienda de productos educativos
- **/contacto** - Información de contacto y formulario

### 👤 **Sistema de Usuarios**
- **/login** - Inicio de sesión
- **/registro** - Registro de nuevos usuarios
- **/perfil** - Perfil de usuario (requiere autenticación)
- **/logout** - Cerrar sesión

### 🛒 **E-commerce**
- **/tienda** - Catálogo de productos
- **/carrito** - Carrito de compras
- **/checkout** - Proceso de pago y finalización de compra

### 📚 **Inscripciones**
- **/inscripcion** - Formulario de inscripción de estudiantes
- **/inscripcion/exitosa** - Confirmación de inscripción exitosa

### 📰 **Noticias Dinámicas**
- **/noticias** - Listado de todas las noticias
- **/noticias/{id}** - Detalle de noticia específica

### 🔧 **Panel Administrativo** (Requiere privilegios admin)
- **/admin** - Dashboard administrativo
- **/admin/usuarios** - Gestión de usuarios
- **/admin/productos** - Gestión de productos
- **/admin/contenido** - Gestión de contenido web
- **/admin/noticias** - Gestión de noticias
- **/admin/programas** - Gestión de programas educativos
- **/admin/inscripciones** - Gestión de inscripciones
- **/admin/ordenes** - Gestión de órdenes de compra
